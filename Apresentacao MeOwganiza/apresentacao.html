Demonstração prática

Simular → aplicar → desfazer

terminal · bash
$ python meowganiza.py demo sandbox_teste
 12 arquivos de exemplo criados em sandbox_teste/

$ python meowganiza.py organize sandbox_teste
 Plano gerado: 12 movimentos, 0 conflitos. Nada foi alterado ainda.

$ python meowganiza.py organize sandbox_teste --apply
 12 arquivos organizados. Journal salvo para desfazer.

$ python meowganiza.py undo --latest
 Última execução revertida. Pasta voltou ao estado anterior.
Sem --apply: apenas préviaCom --apply: executarundo: reverter

Outros modos: doctor · interactive · web
